MYEXCEL 2026 — ВЕРСИЯ 11

1. Оставьте index.html, style.css и script.js в одной папке.
2. Откройте index.html в Chrome, Edge или Safari.
3. Для формулы начните ввод со знака =.

Примеры:
=A1+B1
=A1*2
=SUM(A1:A5)
=AVERAGE(B1:B10)
=MIN(A1:A10)
=MAX(A1:A10)
=COUNT(A1:A10)
=IF(A1>100,1,0)

«Сохранить» создаёт файл проекта JSON.
«Открыть» принимает проекты JSON и простые CSV-файлы.
«CSV» экспортирует таблицу для открытия в Excel.
Все изменения автоматически сохраняются в браузере.
